# LAWMA 360 customer app

Resident waste-service application built with React, TanStack Start, Vite and
Supabase. Deployed independently to Vercel using Nitro server functions.

Install: `bun install --frozen-lockfile`
Develop: `bun run dev`
Build: `bun run build`
Test: `bun run test`

See [deployment configuration](docs/deployment.md), [.env.example](.env.example),
and the [cross-app message contract](docs/app-messages.md).
